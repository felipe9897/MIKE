# Checklist de abertura publica

- [ ] Repositorio criado como privado e separado do monorepo operacional.
- [ ] Historico comeca na arvore auditada, sem importar commits antigos.
- [ ] Auditor local e GitHub Actions aprovados.
- [ ] Varredura de segredos independente aprovada.
- [ ] Dependencias e componentes de terceiros possuem licencas compativeis.
- [ ] Nenhum dado de cliente, conversa, banco, log, backup ou infraestrutura privada.
- [ ] Codigo que controla o computador exige consentimento e possui limites documentados.
- [ ] Instaladores sao publicados como Releases, com SHA-256 e assinatura quando disponivel.
- [ ] Protecao da branch principal e revisao obrigatoria configuradas.
- [ ] Security Advisories e Dependabot habilitados.
- [ ] Discussao, patrocinio e canal de suporte revisados antes de tornar publico.
