# Checklist de abertura publica

- [x] Repositorio criado como privado e separado do monorepo operacional.
- [x] Historico comeca na arvore auditada, sem importar commits antigos.
- [x] Auditor local e GitHub Actions aprovados.
- [x] Varredura de segredos independente aprovada.
- [x] Dependencias e componentes de terceiros inventariados e mantidos sob suas licencas.
- [x] Nenhum dado de cliente, conversa, banco, log, backup ou infraestrutura privada.
- [x] Codigo que controla o computador exige consentimento e possui limites documentados.
- [ ] Instaladores sao publicados como Releases, com SHA-256 e assinatura quando disponivel.
- [ ] Protecao da branch principal e revisao obrigatoria configuradas imediatamente apos a abertura publica.
- [x] Alertas de vulnerabilidade e correcoes automaticas habilitados.
- [ ] Discussao, patrocinio e canal de suporte revisados antes de tornar publico.
